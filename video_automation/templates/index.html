▶ YouTube Upload
Setup steps:
1. Go to console.cloud.google.com → create a project → enable YouTube Data API v3
2. Create OAuth 2.0 credentials (Desktop app) → download JSON → save as credentials/youtube_client_secrets.json
3. Run python main.py setup --platform youtube to authenticate and get the refresh token.
🎵 TikTok Upload
Setup steps:
1. Go to developers.tiktok.com → create an app → apply for Content Posting API
2. Wait for approval (1–5 business days)
3. Generate an access token via OAuth 2.0 and paste it above.
